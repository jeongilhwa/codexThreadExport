# Drift Review

## Use When

- Docs and repo structure might no longer match.

## Steps

1. Read `docs/drift-management/drift-definition.md`.
2. Verify whether the mismatch is temporary, intentional, or accidental.
3. Add or update a drift item with impact, owner, and remediation path.
4. If the fix is small and safe, fix it in the same change.
5. If not, leave the repo unchanged and document the next planned remediation.
