# Task Intake

## Use When

- A new request arrives and the correct owner or scope is not yet obvious.

## Steps

1. Read `README.md`, `AGENTS.md`, and the most relevant active plan.
2. Classify the request as frontend, backend, test, docs, or review.
3. Identify affected folders and whether the task crosses ownership boundaries.
4. Decide whether a new active plan is needed.
5. Record known risks, blockers, or drift interactions before implementation starts.
