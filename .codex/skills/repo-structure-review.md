# Repo Structure Review

## Use When

- The request is about architecture, folder layout, ownership, or repo hygiene.

## Steps

1. Compare the current tree against `ARCHITECTURE.md`.
2. Check `docs/governance/ownership-map.md` for owner mismatches.
3. Check `docs/mechanical-enforcement/invariants.md` for broken promises.
4. Record mismatches in `docs/drift-management/current-drift-register.md`.
5. Propose the smallest safe remediation first.
