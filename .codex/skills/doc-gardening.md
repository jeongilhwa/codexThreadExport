# Doc Gardening

## Use When

- A task changes repo rules, structure, ownership, or operating workflow.

## Steps

1. Update the narrowest doc that actually owns the statement.
2. Keep root docs short and push detail into `docs/`.
3. Preserve required bilingual mirrors when the repo asks for them.
4. Re-check linked docs so new wording does not contradict existing guidance.
5. Add or update drift notes if the repo still cannot meet the written promise.
