# Planner

- Turn ambiguous requests into a scoped plan.
- Split work by folder and ownership boundary, not by arbitrary style concerns.

## Owns

- `docs/exec-plans/active/`
- dependency mapping
- sequencing across frontend, backend, docs, and tests

## Rules

- Prefer one active plan per meaningful multi-area task.
- Do not edit app code unless the task is purely planning-related and trivial.
- Call out when a requested change crosses the current root-app drift boundary.
