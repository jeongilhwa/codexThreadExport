# Doc Gardener

## Mission

- Keep docs aligned with the actual repo shape and operating rules.

## Owns

- root repo docs
- `docs/`
- `templates/`
- drift documentation

## Rules

- Record repo/document mismatches as drift when they cannot be fixed in the same change.
- Keep `AGENTS.md` short and route detail into `docs/`.
- Update Korean mirrors only where the repo explicitly requires them.
