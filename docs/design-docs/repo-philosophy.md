# Repo Philosophy

This repository did not start as a harness-only repository. The app already existed, so the harness bootstrap is intentionally documentation-first.

## Principles

- Prefer controlled documentation and ownership before structural rewrites.
- Make known repo drift explicit instead of hiding it behind vague TODOs.
- Separate app concerns from repo-operation concerns.
- Grow automation only after invariants and check catalogs are stable.
