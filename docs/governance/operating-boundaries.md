# Operating Boundaries

- Do not move the current app layout into `src/` without an explicit migration plan.
- Do not rewrite root docs into long manuals; keep detail in `docs/`.
- Do not claim automation exists when the repo only documents future checks.
- Do not treat `bin/` and `obj/` as sources of truth.
- Do not change user-owned in-progress app files as part of repo bootstrap work unless explicitly asked.
